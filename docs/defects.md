# Ревизия шаблона: вариант 3

Источник: https://gitverse.ru/dgimatdinov/kr2-template
Исходный коммит: `3ee6c4bfda24df8cb4d61f8a27031813b3238338`.
Номера строк ниже относятся к исходному Dockerfile, до исправления.

| № | Файл, строка | Дефект | Последствие | Исправление |
|---|---|---|---|---|
| 1 | Dockerfile:1 | `python:latest` | Повторная сборка может получить другую основную версию Python; не используется общий базовый образ ПР7 | `python:3.12-slim` |
| 2 | Dockerfile:5 | `COPY . .` до установки зависимостей | Изменение app.py инвалидирует слой установки всех зависимостей | Сначала COPY requirements.txt, pip install, затем COPY app.py |
| 3 | Dockerfile:5; отсутствует .dockerignore | В контексте присутствует .env | Пароль попадает в слой образа и доступен получателю образа; удаление следующим слоем его не убирает | Исключить .env и .git, копировать только необходимые файлы |
| 4 | .env; отсутствует .gitignore | Пароль отслеживается Git | Доступен всем читателям репозитория и остаётся в истории | Удалить файл из текущей версии; добавить .gitignore; сгенерировать новый пароль только на VM |
| 5 | Dockerfile:6 | pip сохраняет кэш | Образ содержит ненужный кэш загрузок, увеличиваются размер и передача | `pip install --no-cache-dir` |
| 6 | Dockerfile:8 | EXPOSE 8000 не соответствует варианту | Метаданные образа описывают неверный порт; EXPOSE сам порт не публикует | EXPOSE 8003 и согласованная команда запуска/Compose |
| 7 | Dockerfile:9 | bind 127.0.0.1 внутри контейнера | DNAT пересылает трафик на сетевой интерфейс контейнера, а приложение слушает только его loopback | bind 0.0.0.0:8003; публикация хоста ограничена 127.0.0.1 |
| 8 | Dockerfile:9 | CMD в shell-форме | PID 1 занимает оболочка, доставка SIGTERM приложению может нарушаться, остановка задерживается | CMD как JSON-массив с gunicorn |
| 9 | Dockerfile:1-9 | Нет USER | Приложение запускается от root внутри контейнера, увеличивая последствия уязвимости | Создать системного пользователя app и установить USER app |

Логика app.py и requirements.txt сохранены. По заданию допускается только комментарий `# KR2: Zabotkin` для опыта с кэшированием.
